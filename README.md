# 無言トーク

**しゃべらずに、エピソードを伝えきれ。**

声を出さずに、身ぶり・表情・動きだけでエピソードトークを伝えるパーティゲームです。
話し手は選んだ「トーク要素」（形容詞・動詞・名称・接続語）だけを読み上げ機能で補助に使えます。聞き手は導入・展開・結論がどれだけ伝わったかを採点します。1 台の端末を囲んで 2 人以上で遊べます。

## 遊び方

1. **エピソードを用意**：「🎲 エピソードを出力」で収録 20 本からランダム出題。または「✏️ 自分で記入」で三行（導入／展開／結論）を書き、Claude API でトーク要素を抜き出す。
2. **要素を選ぶ**：話し手がトーク要素を 1〜4 個選ぶ。
3. **スタート**：「▶ ゲームスタート」で 3 分カウント開始。話し手は無言で伝え、要素カードはタップで読み上げられる。
4. **採点**：聞き手はプレイ中に、導入・展開・結論の 3 本のバー（0〜100）で再現度を付ける。
5. **終了**：「🙌 伝わった！」か時間切れで終了。3 本の平均点が点数ログに残る。次は「↺ やり直し」。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成する（例：`mugon-talk`）。
2. このフォルダのファイルを push する。
   ```sh
   git init
   git add index.html episodes.js episodes.json README.md SPEC.md
   git commit -m "無言トーク"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/mugon-talk.git
   git push -u origin main
   ```
3. リポジトリの **Settings > Pages** を開き、Source を「Deploy from a branch」、Branch を **`main`** / **`/ (root)`** にして Save。
4. 数分後、`https://<ユーザー名>.github.io/mugon-talk/` で遊べます。

## ローカルで遊ぶ

`index.html` をダブルクリックしてブラウザで開くだけで動きます。
エピソードデータは `episodes.js` を `<script>` タグで読み込む方式のため、ローカルサーバーは不要です（`index.html` と `episodes.js` を同じフォルダに置いてください）。

## Claude API キーについて

「自分で記入」の要素抽出には Anthropic の Claude API キーが必要です（ランダム出題だけなら不要）。

- キーはブラウザから Anthropic API へ直接送信され、ページの配信元には送られません。
- 「このブラウザにキーを保存する」をオンにすると localStorage に平文で保存されます。共有端末ではオフにしてください。
- API 利用料はキーの所有者に発生します。公開ページやリポジトリにキーを書き込まないでください。
